Project 01

Generative Data Art

A restaurant network from Bangalore, drawn four different ways — from first rough experiments to a published paper.

Beat A — First passes

Thin lines on black. No palette, no layout algorithm, no idea yet what the shape wanted to be — just Python, a plotting window, and a few thousand edges.

Beat B — Legible

Same graph, same rule. Now the colour means something: community detection sets the hue, modularity sets the grouping, centrality sets the size.

Beat C — In Processing

Rewritten in Java. The same rule, run again and again — colour is the only variable.

Sixteen runs of one generative rule, side by side. Nothing changes but the palette.

Beat D — The paper

Network Analysis and Generation of Data Art from Restaurants Data

The visuals came out of a co-authored paper on Bangalore's restaurant scene. We took Zomato's data — cuisines, menus, featured dishes, reviews — and built a similarity network across 8,792 restaurants: TF-IDF embeddings per restaurant, then nearest-neighbour matching on the twenty closest, quantile-weighted into 147,424 edges.

Community detection ran four ways — Label Propagation, Louvain with a Constant Potts Model, Demon, and Bayesian statistical inference. Demon read best: it grouped restaurants by region — Tamil Nadu, Bihar, the Delhi–Punjab–Haryana belt — with no location data in the graph at all.

The argument the paper makes is the one this page is built on: a bar chart would have told you the degree distribution follows a power law. It would not have shown you which communities sit next to each other, or which restaurant is quietly bridging two cuisines it has no business bridging.

Project 02

AI Image Dashboard

Microsoft Ethical Tech Summit

Led an AI image dashboard project for Microsoft, presented at the Microsoft Ethical Tech Summit.

The dashboard used AI-generated images and voices to tell the stories of people experiencing suffering around the world, running on a large screen at the summit.

The point of it was the hard part: using generative image and voice models responsibly enough to carry real human stories, rather than to make pretty pictures.
